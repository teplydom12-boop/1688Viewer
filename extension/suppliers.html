2. Отбор карточек через Claude — по желанию

Скачайте инструкцию и JSON, вручную прикрепите их в Claude. Попросите сохранить ответ в JSON и загрузите его сюда. Анализ идёт только по названию: изображения и ссылки не передаются. Полностью одинаковые названия передаются один раз для всех сайтов; решение применяется ко всем связанным карточкам. Расширение само не обращается к AI-сервисам.

Без загруженных решений проверяются все карточки.

Описание изменено. Скачайте новый JSON для Claude или сбросьте отбор перед проверкой поставщиков.

По умолчанию выгружаются все названия. Для больших заданий можно выбрать порции: объём контекста и длина ответа Claude ограничены. Отсутствующие решения остаются неоценёнными. Проверяются подходящие, спорные и неоценённые карточки. Явно неподходящие сохраняются отдельной категорией. Новое описание сбрасывает прежние решения; смена размера порций сохраняет категории и создаёт новые файлы задания. Ручная смена категории применяется ко всем карточкам с точно таким же названием.
